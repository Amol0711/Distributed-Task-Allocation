# Synthetic benchmark datasets

The repository contains two deterministic synthetic benchmarks. No real orbital,
flight, remote-sensing, agronomic, personal, or confidential measurements are
included.

- `SAT-COV-V1/` contains a micro-satellite constellation, target catalogue,
  sensor-product quality table, and synthetic environmental stream.
- `UAV-AG-V1/` contains UAV initial conditions, a synthetic field map, and a
  synthetic environmental stream.

Additional trial streams are generated from `seeds/trials.csv`.
